Open interactive noVNC

Keyboard/clipboard in embedded cross-origin noVNC is browser-dependent. Open interactive noVNC/Detached noVNC uses the same Docker browser session and is the reliable path for typing credentials.

For paste: disable keyboard extensions such as Vimium/cVim on the noVNC page, open noVNC's side toolbar clipboard panel, paste text there, then focus the remote input and press Ctrl+V inside the remote browser.
