Browser compatibility: Firefox, Zen, and Safari are intentionally routed to the detached {{ event.operator_label | lower }} tab because embedded WebRTC and clipboard focus are unreliable there. The detached tab controls the same session and keeps OpenSesame open for resolution.

Choose the desired entry in your host clipboard manager first, then click an input in the remote browser and paste normally with Ctrl/Cmd+V or your desktop paste binding. The paste action syncs the selected clipboard entry into the remote session. OpenSesame stores only the handoff URL and event metadata, never credential values or clipboard contents.

Chrome/Chromium usually supports the embedded OpenSesame/Neko WebRTC frame. Firefox, Zen, and Safari are supported through the detached {{ event.operator_label | lower }} link instead of the iframe; it controls the same browser session.
